# Expense Tracker

Expense Tracker is a beginner-friendly Python program for recording and analyzing personal expenses.

It stores expenses by year, month, and date, then provides summaries and graphs to help understand spending.

## Features

- Add new expenses
- Add multiple expenses on the same date
- Organize expenses by year, month, and date
- Display expenses in sorted order
- Save expenses to a CSV file
- Display yearly and monthly financial summaries
- Calculate yearly totals and averages
- Calculate monthly totals and averages
- Find the most expensive category for each year and month
- Create year-wise and month-wise line graphs
- Save graphs as PNG image files

## How to run

### 1. Create a virtual environment

```bash
python3 -m venv .venv
```

### 2. Activate the virtual environment

On Linux or macOS:

```bash
source .venv/bin/activate
```

On Windows:

```bash
.venv\Scripts\activate
```

### 3. Install the required packages

```bash
pip install -r requirements.txt
```

### 4. Run the program

```bash
python3 financial_analysis.py
```

Follow the instructions shown in the menu to add expenses, view summaries, save CSV data, or create graphs.
